# 速報の見張り

`update.py` が5分おきに SEIKO の速報を見て、新しい結果が出たらアプリに反映して公開する。
launchd `com.fukuda.swim.intercollege-2026`（StartInterval 300）。2026-09-07 09:00 に自分で止まる。

- 動く時間帯: 大会4日間の 9:00〜21:00（夜中は回さない）
- `いま速報を取り込む.command` … ダブルクリックで今すぐ取り込み（時間帯を無視）
- `log.txt` … 毎回の記録。生きている証拠
- `.seen.json` … 取り込み済みの競技No.

**検算に落ちたら公開しない。** 組・水路の重複、順位と記録の逆転、ビルドの検算（件数）の
どれかに引っかかったら反映を止めて通知する。鹿児島出身の選手の結果は必ず通知する。
