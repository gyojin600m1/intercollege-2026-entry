# 第102回 日本学生選手権水泳競技大会 競泳競技（インカレ）エントリー確認（非公式）

2026年9月3日(木)〜6日(日)　東和薬品RACTABドーム（大阪府門真市三ツ島3丁目7-16）
※9月2日(水)は公式練習日／開門 8:00・1日目の開会式 10:00

選手・保護者・応援する人が出場種目とエントリータイムを調べるための、**個人が作った非公式の確認用ページ**です。
公式のスタートリストではありません。

👉 https://gyojin600m1.github.io/intercollege-2026-entry/

## できること

- **選手** … 名前（ひらがな・カタカナでも可）や大学名で検索。学校ごとにまとめて表示
- **種目** … 全26種目を公式のエントリーランキング順で一覧
- **日程** … 競技No.1〜94のプログラム。**予定時刻と組数**入り
- **リレー** … 6種目252チームをタイム順に。**シード校／団体出場校**の別つき
- **大会情報** … 競技方法・申込制限・タイムと印の見かた
- **⭐鹿児島** … 鹿児島の2大学（32名）をワンタップで絞り込み
- **🎓進路** … 鹿児島の高校で泳いでいた17名を、高校ごとにまとめて表示（6高校 → 12大学）

## 「進路」タブについて

高校時代に**鹿児島県の登録で大会に出ていた記録**をもとにしています。
生まれ育ちまでは分からないため「出身」とは書いていません。
調べられる範囲が2021年度以降のため、載っていない選手もいます。

## 組・レーンとリレーの泳者は入っていません

エントリー段階の公開資料には**組・レーン**も**リレーの泳者・泳順**も含まれていません。
どちらも大会プログラム／スタートリストで発表されるので、このページでは出していません。

## タイムと印の見かた

- タイムは**長水路の指定期間ベスト**です。並び順は公式のエントリーランキングそのままです
- **短水路◯◯** … 指定期間に長水路の記録が無く、短水路の記録で申し込んだ選手（5名）。並び順は最後になります
- **支部上位枠** … 標準記録ではなく、支部選手権の上位で出場する選手
